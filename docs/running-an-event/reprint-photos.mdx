# Reprint photos

Guests can print extra copies of their photo after the first one. In the app this is called **Extra copies**. Turn it on and set a timeout in **Booth**.

1. Open **Booth** in the menu. On the **Guest steps** tab, tap **Extra copies**.
2. Switch **Extra copies** on. The line under it reads "After printing, guests can print more of the same."
3. Set **Most extra copies**, the most extra copies a guest can pick, from 1 to 10. Tap **−** or **+**.
4. Switch **Close by itself** on. The line under it reads "Return automatically if the guest does not choose extra copies." Guests often forget to dismiss the screen.
5. Set **Close after**, the number of seconds before it closes, from 5 to 60.
6. Use the back arrow to return to **Booth**. The **Extra copies** row now shows the limit, for example "Up to 3 copies", or **Off**.

1. **Extra copies** — turns extra copies on.
2. **Most extra copies** — the limit.
3. **Close by itself** — returns automatically if the guest does not choose.
4. **Close after** — how many seconds it waits before closing. It shows only when **Close by itself** is on.

Guests see the question **Extra copies?** with a button such as **Print 2 more** and **No, thank you!**.

If you use [Online photos](../app/online-photos.mdx), extra copies use the same QR code and the same online page as the first print.

:::tip
Each extra copy uses paper. Keep a spare roll nearby at busy events. See [Paper and reorders](../printer-and-paper/paper-and-reorders.mdx).
:::
