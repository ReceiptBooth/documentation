# Reprint photos

Guests can print extra copies of their photo after the first one. Turn it on and set a timeout in **Booth Customisation**.

1. Open **Booth Customisation** in the sidebar.
2. Enable the **Reprint photo** feature.
3. Set the automatic timeout. This closes the reprint prompt after a number of seconds, because guests often forget to dismiss it.

![Booth Customisation screen with the reprint and countdown options numbered](../img/annotated/booth-customisation-annotated.png)

Look under **Camera Capture** and the countdown options on this screen when you set reprint behaviour and timeouts.

:::tip
Each extra copy uses paper. Keep a spare roll nearby at busy events. See [Paper and reorders](../printer-and-paper/paper-and-reorders.mdx).
:::
