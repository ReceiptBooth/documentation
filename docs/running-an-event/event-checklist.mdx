# Event checklist

Use this whenever you set the booth up somewhere new.

## The day before

1. Charge the tablet and check the app is up to date in the Play Store.
2. Make sure the [tablet settings](../getting-started/tablet-settings.mdx) are applied, so the screen will not dim or sleep.
3. Load a fresh paper roll. See [Refilling paper](../printer-and-paper/refilling-paper.mdx).
4. Run a **Test print** from the **Printer** page. See [Printer settings](../printer-and-paper/printer-settings.mdx). {/* TODO(boss): Instax Polaroid, ships in 1.1? */} With Instax Polaroid, tap **Print test card** on each printer and check **Film** and **Battery**. See [Instax Polaroid](../app/instax-polaroid.mdx#add-printers).
5. Check your theme and print design look right. See [Interface and print templates](../app/templates.mdx).
6. Using [Online photos](../app/online-photos.mdx)? Check **Booth**, **Saving** has **Online photos (QR)** on, then take a test session, scan the code with your own phone and check the photo opens. If your print design has a QR code, do a test print and scan that too.
7. Pack a spare paper roll. Rolls print about 200 to 400 photos each, depending on the layout, and the app does not show how much paper is left.

## At the venue

1. Place the booth in a bright spot near a power socket. Dim rooms can cause [horizontal lines on prints](../printer-and-paper/lines-on-prints.mdx).
2. Connect the power cable at the back of the booth. Confirm the printer is on and the tablet is charging.
3. Open the app and look at **Home**. It should say **Ready for guests**, with no red **!** marks. Online photos need internet: connect the tablet to the venue Wi-Fi or a phone hotspot. The **Online photos** line should say **All photos online**.
4. Tap **Start booth**. If the app asks a question (a printer that is not connected, or "No internet. Photos will go online later."), read it before you tap **Start anyway**.
5. Take one test photo and check the print.
6. Check [reprints](./reprint-photos.mdx) are set up the way you want, including the timeout.

## During the event

- Keep an eye on the paper roll.
- To leave photo mode, [tap the top-left corner five times](./exit-photo-mode.mdx).
- If something looks wrong, see [Troubleshooting](../troubleshooting.mdx).
- With Online photos on, a client can ask for a photo to be taken down. Open **Home**, **Online photos**, and use **Remove from the internet**.

## Afterwards

1. Leave photo mode and check **Home**. If **Online photos** says photos are waiting, connect the tablet to the internet so they go up.
2. Check the **Printer** page for the connected printer.
3. [Reorder paper](../printer-and-paper/paper-and-reorders.mdx) so you have a spare roll for next time.
