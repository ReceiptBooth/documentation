# Event checklist

Use this checklist whenever you set the booth up somewhere new, whether it is a wedding, a pop-up or your own cafe.

## The day before

1. Charge the tablet and check the app is up to date in the Play Store.
2. Make sure the [tablet settings](../getting-started/tablet-settings.mdx) are applied, so the screen will not dim or sleep.
3. Load a fresh paper roll. See [Refilling paper](../printer-and-paper/refilling-paper.mdx).
4. Run a **Test print** from the **Printer** screen. See [Printer settings](../printer-and-paper/printer-settings.mdx).
5. Check your theme and print template look right. See [Interface and print templates](../app/templates.mdx).
6. Pack a spare paper roll. Rolls print about 200 to 400 photos each, depending on the layout, and the app does not warn you when the paper runs out.

## At the venue

1. Place the booth in a bright spot near a power socket. Dim rooms can cause [horizontal lines on prints](../printer-and-paper/lines-on-prints.mdx).
2. Connect the power cable at the back of the booth. Confirm the printer is on and the tablet is charging.
3. Open the app, then tap **Enter Photo Mode**.
4. Take one test photo and check the print.
5. Check [reprints](./reprint-photos.mdx) are set up the way you want, including the timeout.

## During the event

- Keep an eye on the paper roll.
- To leave photo mode, [tap the top-left corner five times](./exit-photo-mode.mdx).
- If something looks wrong, see [Troubleshooting](../troubleshooting.mdx).

## Afterwards

1. Leave photo mode and check the **Printer** screen for the connected printer.
2. [Reorder paper](../printer-and-paper/paper-and-reorders.mdx) so you have a spare roll for next time.
