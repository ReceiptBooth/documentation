# Features & links

We're constantly updating the application to include new features and bug fixes. The application is available in all countries, and it is only compatible with our printers and tablets.

Download the application here: https://play.google.com/store/apps/details?id=com.receiptbooth.receiptbooth

Application version: v1.0, 19 May 2026

## Current features:
1. Automatic photo booth app to take photos and print
2. Fully customisable print templates and app screens
3. Adjust sound effects, print brightness & textures, and more!

## Planned features:
1. 4-cut photo print outs
